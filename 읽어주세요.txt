유포리아투어 홈페이지 — 이번 작업분 (2026-10-14)
================================================

저장소: euforia-jpg/ornate-chebakia-a4180f
아래 7개 파일을 저장소의 같은 자리에 덮어쓰시면 됩니다.

  product.html                      ← 상품 상세 (일정 지도)
  products.js                       ← 상품 자료 (13개 상품에 경로 추가)
  admin.html                        ← 관리자 (상품추가 · PDF 자동채움 · 문의함 연락)
  builder.html                      ← 견적·일정표 만들기 (인쇄 양식 · 로고 워터마크)
  data/builder.json                 ← 입장지 자료 (카사 바트요 · 카사 밀라 · 몬세라트)
  netlify/functions/admin-api.js    ← 관리자 저장 기능 (PDF 업로드)
  netlify/functions/inbox.js        ← 문의함 (상태 · 메모 · 메일)

올리는 방법
-----------
1. 관리자 화면(admin.html)이 열려 있으면 먼저 닫아 주십시오.
   열어 둔 채로 올리면 저장 시 products.js 가 덮어써질 수 있습니다.
2. GitHub 저장소에서 Add file → Upload files 를 누르고
   위 파일들을 끌어다 놓습니다.
   netlify/functions/ 와 data/ 안의 파일은 그 폴더로 들어가서 올려 주십시오.
3. Commit changes 를 누르면 Netlify 가 1~2분 안에 배포합니다.
