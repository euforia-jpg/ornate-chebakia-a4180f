# 골프장 사진 사용 허락 요청 메일

대부분의 클럽은 홍보가 되므로 **미디어 키트(press kit)** 를 그냥 보내 줍니다.
보내실 때 **어디에 쓸지와 출처 표기 방식**을 분명히 적는 것이 핵심입니다.

## 사진을 받으시면

1. 골프장마다 **가로로 긴 사진 1~2장**(권장 1600×1000 안팎)을 고르세요.
2. 파일 이름을 골프장 id 로 지어 주세요 — `valderrama.jpg`, `monte-rei.jpg` 처럼요.
   id 는 `golf-clubs.json` 에 적혀 있습니다.
3. 받은 **크레딧 문구**(예: `© Real Club Valderrama`)를 같이 적어 주세요.

파일과 크레딧을 주시면 카드마다 사진을 올리고, 사진 아래에 출처를 표기해 드리겠습니다.
